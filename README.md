# 팀 일정 공유 — 하루 타임테이블

9명이 함께 쓰는 하루 일정 공유 사이트입니다.
06:00~22:00을 30분 단위로 나눈 표에 각자 일정을 등록해 서로 보고,
"회의 시간 찾기"로 모두가 비는 시간에 전원의 회의를 한 번에 잡습니다.

## 처음 공개하기 (약 10분)

### 1단계. 사이트 배포 (Vercel, 무료)

1. [vercel.com](https://vercel.com) 가입 (GitHub 계정으로 로그인)
2. **Add New → Project** → 이 저장소(`team-schedule`) Import
3. 설정 변경 없이 **Deploy** 클릭
4. 배포가 끝나면 `https://team-schedule-xxxx.vercel.app` 같은 주소가 생깁니다

여기까지만 해도 화면은 열리지만, 일정이 **각자 브라우저에만** 저장됩니다.
팀원끼리 서로의 일정을 보려면 2단계가 필요합니다.

### 2단계. 서버 저장 연결 (Supabase, 무료)

1. [supabase.com](https://supabase.com) 가입 → **New Project** (무료 요금제)
2. 프로젝트가 준비되면 좌측 **SQL Editor**에서 아래 SQL을 한 번 실행:

```sql
create table schedule_members (
  id text primary key,
  name text not null,
  color text,
  sort int
);
create table schedule_entries (
  id text primary key,
  date text not null,
  member_id text not null,
  start_min int not null,
  end_min int not null,
  title text not null,
  memo text,
  created_at timestamptz default now()
);
create index schedule_entries_date_idx on schedule_entries (date);
alter table schedule_members enable row level security;
alter table schedule_entries enable row level security;
```

3. **Project Settings → API**에서 두 값을 복사:
   - `Project URL` (예: `https://xxxx.supabase.co`)
   - `service_role` 키 (⚠️ secret — 외부 공개 금지)
4. Vercel 프로젝트 → **Settings → Environment Variables**에 추가:

| 이름 | 값 |
|---|---|
| `SUPABASE_URL` | 위에서 복사한 Project URL |
| `SUPABASE_SERVICE_KEY` | 위에서 복사한 service_role 키 |

5. **Deployments → 최신 배포 → Redeploy**를 눌러 반영

### 확인

사이트에 접속했을 때 상단에 "팀 공유 중"이라고 나오면 성공입니다.
"오프라인 모드" 배너가 보이면 환경변수를 다시 확인하세요.

## 휴대폰·PC에 앱으로 설치하기

앱스토어 등록 없이, 사이트 주소만 있으면 홈 화면에 앱처럼 설치됩니다 (PWA).
설치하면 주소창 없는 전체 화면으로 열리고, 인터넷이 없어도 마지막으로 본 일정을 확인할 수 있습니다.

| 기기 | 설치 방법 |
|---|---|
| 아이폰 · 아이패드 | Safari로 접속 → 아래 **공유 버튼** → **"홈 화면에 추가"** |
| 안드로이드 | Chrome으로 접속 → 오른쪽 위 **⋮** → **"앱 설치"** |
| PC (Chrome/Edge) | 주소창 오른쪽 **설치 아이콘** 클릭 |

사이트 상단의 **"📲 앱 설치"** 버튼을 눌러도 됩니다 (설치 가능한 기기에서만 표시).

오프라인일 때는 **보기 전용**으로 동작합니다 — 마지막으로 받은 일정을 보여주고,
인터넷이 연결되면 자동으로 최신 상태로 돌아옵니다.

## 사용 방법

- **일정 등록**: 본인 열의 빈 칸 클릭 → 제목·시간 입력 → 저장. 여러 명을 함께 선택하면 각자의 칸에 같은 일정이 들어갑니다.
- **일정 수정/삭제**: 일정 블록을 클릭(탭)하면 수정 창이 열립니다.
- **시간 옮기기·늘리기**:
  - PC: 블록을 끌면 시간대가 이동하고, 위/아래 가장자리를 끌면 시작·끝 시간이 30분 단위로 조절됩니다.
  - 휴대폰: 블록을 **길게 누른 뒤(약 0.3초)** 끌어야 움직입니다(실수로 옮겨지는 것을 막기 위함). 길게 누르면 테두리가 금색으로 바뀌고 진동이 울립니다. 위·아래의 **손잡이(⎯)** 를 길게 눌러 끌면 시작/끝 시간이 조절되고, 끄는 동안 바뀌는 시간이 가운데에 크게 표시됩니다.
- **이름 바꾸기**: 표 맨 위의 이름 클릭. 처음에는 "팀원 1~9"로 되어 있습니다.
- **팀원 추가/제거**: 표 오른쪽 끝의 `＋`를 누르면 추가, 이름을 누른 창의 "팀원 제거"로 제거됩니다 (그 사람의 일정도 함께 삭제).
- **전체 일정 추가**: 상단 "📌 전체 일정 추가" 버튼 — 회의뿐 아니라 교육·행사·휴무처럼 모두에게 해당하는 일정을 한 번에 등록합니다.
- **공통 일정은 한 줄로**: 여러 명에게 같은 제목·시간으로 등록된 일정은 그 사람들의 열을 잇는 **하나의 가로 막대**로 표시되고, 오른쪽에 "전원"/"N명" 표시가 붙습니다. 막대를 드래그하면 참석자 전원의 시간이 함께 바뀌고, 클릭해서 참석자를 추가·제외하거나 한 번에 삭제할 수 있습니다.
- **겹치는 일정**: 한 사람의 일정이 서로 겹치면 그 시간대에서만 폭을 나눠 나란히 표시됩니다 (겹치지 않는 일정은 항상 전체 폭).
- **회의 시간 찾기**: 상단 버튼 → 참석자·시간대·최소 시간을 고르면 모두가 비는 시간이 초록색으로 표시되고, 클릭하면 전원의 일정으로 회의가 잡힙니다. (점심 12~13시는 기본 제외)
- **휴대폰에서 보기**: 좁은 화면에서는 팀원 전체가 **가로 스크롤 없이 한 화면**에 들어오도록 자동으로 압축해서 보여줍니다. 글씨를 키워 자세히 보려면 상단 **"↔ 넓게"** 버튼을 누르세요 (설정은 기억됩니다).
- **날짜 이동**: 상단 ◀ ▶ 버튼 또는 날짜를 눌러 달력에서 선택.
- 화면은 30초마다, 그리고 탭에 다시 돌아올 때 자동으로 새로고침됩니다.

## 일정표 이미지로 공유하기

상단 **"📷 복사"** 버튼을 누르면 보고 있는 날짜의 일정표 전체를 깔끔한 **이미지 한 장**으로 만들어 줍니다.

- **PC**: 클립보드에 복사됩니다 — 카톡·텔레그램 채팅창에 **붙여넣기(Ctrl+V)** 하면 끝.
- **휴대폰**: 공유 창이 떠서 카카오톡·텔레그램 등 보낼 앱을 바로 고를 수 있습니다.
- 복사가 지원되지 않는 환경에서는 이미지 파일로 저장됩니다.
- 이미지에는 날짜·전체 팀원·공통 일정 막대까지 화면과 같은 모양으로 담기고, 일정이 있는 시간대에 맞춰 위아래가 알아서 잘립니다.

## 엑셀로 주고받기

상단 **"📊 엑셀"** 버튼을 누르면 일정표를 엑셀로 내려받고, 엑셀로 작성한 일정을 한 번에 올릴 수 있습니다.

- **내려받기**: 기간(최대 62일)을 정해 `.xlsx` 파일로 받습니다. 파일에는 `일정` 시트와 `작성방법` 시트(팀원 명단 포함)가 들어 있습니다.
- **올리기**: 받은 파일의 양식 그대로 채워서 올리면 자동 등록됩니다.

| 날짜 | 이름 | 시작 | 종료 | 일정 | 메모 |
|---|---|---|---|---|---|
| 2026-08-17 | 오재준 | 09:00 | 10:30 | 주간 회의 | 회의실 |

- 시간은 `09:00`, `9:00`, `오전 9시`, 엑셀 시간 서식 모두 인식합니다.
- 날짜를 비워 두면 **화면에서 보고 있던 날짜**로 들어갑니다.
- 올리기 전에 **몇 건이 등록되는지, 잘못된 줄은 몇 번째 줄인지** 미리 보여줍니다.
- 옵션: *같은 날짜의 기존 일정을 지우고 넣기*(전체 교체), *명단에 없는 이름은 팀원으로 추가*.
- 여러 사람이 같은 제목·시간으로 들어가면 화면에서 하나의 가로 막대로 합쳐집니다.

## 구조

- `index.html` — 타임테이블 화면 (프레임워크 없는 단일 파일)
- `api/schedule.js` — 일정 저장/조회 서버 함수 (Vercel Serverless + Supabase)
- `vendor/xlsx.min.js` — 엑셀 읽기/쓰기 라이브러리(SheetJS, 사이트에 포함되어 외부 접속 없이 동작)
- 데이터베이스 키(service_role)는 서버 함수에만 존재하며 방문자에게 노출되지 않습니다.
